# NASA Asteroid Tracker

Локальное веб-приложение на Rust показывает астероиды, сближающиеся с Землёй,
для выбранной даты с помощью NASA NeoWs Feed API.

## Запуск

Требуется установленный Rust toolchain. Установите `NASA_API_KEY` в PowerShell
и запускайте приложение в том же окне терминала:

```powershell
$env:NASA_API_KEY = "ВАШ_API_KEY"
cargo run
```

Затем откройте <http://127.0.0.1:3000>. Если ключ не задан, Rust-сервер
использует публичный `DEMO_KEY` с ограниченной квотой. Ключ читает только
сервер: он не встраивается в страницу и не передаётся браузеру. Не помещайте
секретные ключи в исходный код или репозиторий.

При сетевой ошибке сервер показывает кэш выбранной даты, если он доступен.
Кэш хранится в системной папке данных приложения. Сервер по умолчанию слушает
только loopback-адрес `127.0.0.1`.
