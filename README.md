# NASA Asteroid Tracker

Настольное приложение на Rust показывает астероиды, сближающиеся с Землёй,
для выбранной даты с помощью NASA NeoWs Feed API.

## Запуск

Требуется установленный Rust toolchain.

```powershell
cargo run
```

Укажите дату в формате `ГГГГ-ММ-ДД` и нажмите «Загрузить». Для собственного
ключа NASA задайте переменную окружения `NASA_API_KEY`; если она не задана,
приложение использует публичный `DEMO_KEY` с ограниченной квотой. Не помещайте
секретные ключи в исходный код или репозиторий.

При сетевой ошибке приложение показывает кэш выбранной даты, если он доступен.
Кэш хранится в системной папке данных приложения.
